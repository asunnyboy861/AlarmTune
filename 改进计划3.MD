# AlarmTune 铃声系统改进计划

> 基于客户反馈："铃声选择太少，且质量不佳"
> 版本：v3.1 | 日期：2026-07-04（更新 M7/M8 推进决策 + M8.2 分离式架构）

---

## 一、现状诊断

| 维度 | 当前状态 | 行业基准 | 差距 |
|------|---------|---------|------|
| 内置铃声数量 | 5 首 | 20-250 首 | 严重不足 |
| 铃声分类 | 无 | 5+ 类别 | 缺失 |
| Apple Music 集成 | 无 | 竞品标配 | 缺失 |
| 自定义导入 | 代码预留路径，无 UI | 部分竞品支持 | 未实现 |
| 铃声质量 | 偏轻柔，缺刺耳/高唤醒力 | 覆盖全唤醒梯度 | 不足 |
| 预览音量 | 硬编码 0.5 | 应继承用户设置 | 不一致 |

---

## 二、改进模块总览

按功能模块划分，每个模块单一职责、高内聚低耦合：

| 模块编号 | 模块名称 | 优先级 | 说明 |
|---------|---------|--------|------|
| M1 | 铃声数据模型 | P0 | 定义铃声元数据（名称、分类、来源类型），为所有铃声功能提供数据基础 |
| M2 | 铃声资源扩充 | P0 | 从 5 首扩充至 30+ 首，覆盖 5 大分类 |

| M4 | Apple Music 集成 | P1 | 用户从音乐库选歌作为闹钟铃声 |
| M5 | 自定义铃声导入 | P1 | 用户从 Files App 导入音频文件 |
| M6 | 废弃代码清理 | P0 | 清理被替换的旧代码、空目录、硬编码 |
| M7 | Premium 铃声包 + 订阅 | P2 | 免费 30 首 + Premium 订阅解锁更多声音包，建立变现路径 |
| M8 | 视频背景 / AI 铃声 / 随机铃声 | P3 | M8.1 随机铃声防疲劳；M8.2 视频背景（分离式架构，参考 Alarmy）；M8.3 AI 生成铃声 MVP |

### M1：铃声数据模型

#### 3.1 需求描述

当前铃声系统用 `AppConstants.Sound.builtInSounds: [String]` 纯字符串数组表示铃声，无法承载分类、来源类型、文件名映射等元数据。需要定义结构化的铃声模型，为分类浏览、多来源支持提供统一数据基础。

#### 3.2 设计规则

- 遵循现有 `AppConstants` 嵌套枚举的常量组织模式
- 铃声模型使用 `enum` + 计算属性（参考 `AppTheme`/`AlarmCategory` 的枚举模式）
- 分类枚举使用 `CaseIterable` 以支持遍历（参考 `AppTheme.allCases`）
- 文件结构语义化：模型定义放在 `Utilities/Constants.swift` 的 `AppConstants.Sound` 命名空间内，与现有常量组织一致

#### 3.3 代码编写规范

**铃声分类枚举** — 扩展 `AppConstants.Sound`：

```swift
// 在 Constants.swift 的 AppConstants.Sound 枚举内新增

/// 铃声分类，与 AlarmItem.AlarmCategory 风格对齐：rawValue 为显示名、icon 为 SF Symbol、color 为主题色
enum SoundCategory: String, CaseIterable, Identifiable {
    case loud = "Loud"          // 高唤醒力
    case nature = "Nature"      // 自然
    case gentle = "Gentle"      // 舒缓
    case classic = "Classic"    // 经典
    case fun = "Fun"            // 欢快

    var id: String { rawValue }

    var displayName: String {
        switch self {
        case .loud:    return "Loud"
        case .nature:  return "Nature"
        case .gentle:  return "Gentle"
        case .classic: return "Classic"
        case .fun:     return "Fun"
        }
    }

    var icon: String {
        switch self {
        case .loud:    return "speaker.wave.3.fill"
        case .nature:  return "leaf.fill"
        case .gentle:  return "cloud.sun.fill"
        case .classic: return "bell.fill"
        case .fun:     return "music.note.house.fill"
        }
    }

    /// 分类图标背景色，使用系统语义色，兼容深色模式
    var color: String {
        switch self {
        case .loud:    return "red"
        case .nature:  return "green"
        case .gentle:  return "blue"
        case .classic: return "orange"
        case .fun:     return "purple"
        }
    }
}
```

### M2：铃声资源扩充

#### 3.1 需求描述

将内置铃声从 5 首扩充至 30 首，覆盖 5 大分类（Loud/Nature/Gentle/Classic/Fun），每分类 6 首。所有新增铃声为 `.caf` 格式，存放于现有 `Sounds/` 目录。

#### 3.2 设计规则

- 文件命名规则：`{DisplayName去空格}.caf`，与现有 `urlForSound` 的查找逻辑完全兼容（该逻辑会去除空格后匹配文件名）
- 文件存放路径：`Sounds/` 目录（与现有 5 个 .caf 文件同级），非 `Resources/Sounds/`
- 文件大小控制：每首 < 500KB（.caf 格式，15-30 秒片段），总包增量 < 12MB
- 音频质量：44.1kHz / 16bit，确保 AVAudioPlayer 无缝循环播放

### M3：铃声选择器重构

#### 3.1 需求描述

当前 `SoundPickerView` 是一个简单的平铺列表，仅展示 5 个铃声名称。需重构为分类浏览模式，支持：
- 内置铃声按分类分组展示
- 音乐库铃声区域（M4 实现时激活）
- 自定义导入铃声区域（M5 实现时激活）
- 预览音量继承用户设置（而非硬编码 0.5）

#### 3.2 设计规则

- **单一职责**：铃声选择器仅负责展示和选择，不负责铃声数据获取（数据由 `SoundRepository` 提供）
- **代码复用**：分类 Section 复用同一 `SoundCategorySection` 子视图，避免 5 个分类写 5 遍
- **风格一致**：沿用现有 `SoundPickerView` 的视觉风格（圆角高亮行、checkmark/play 图标），沿用 `SettingsView` 的 Form + Section 布局
- **iPad 适配**：沿用 `horizontalSizeClass == .regular` 的自适应模式
- **最小代码**：铃声行视图抽为独立 `SoundRow` 组件（因为 M4/M5 的不同来源铃声行也需复用），符合"三次法则"——内置/音乐库/导入三处复用
- **继承设置**：预览音量从闹钟编辑页的 `volume` 绑定继承，而非硬编码

#### 3.3 文件结构

```
Views/
├── SoundPickerView.swift          ← 重构（替换现有文件）
└── Components/
    └── SoundRow.swift              ← 新增，铃声行组件（内置/音乐库/导入三处复用）
```

> **说明**：`SoundRow` 独立为组件，因为 M4（Apple Music 铃声行）和 M5（导入铃声行）都需要复用相同的行布局。

#### 3.4 代码编写规范

**SoundRow.swift** — 可复用的铃声行组件：

```swift
import SwiftUI

/// 单个铃声行，被内置/音乐库/导入三处复用
/// 设计原则：三次法则 — 内置铃声列表、Apple Music 列表、自定义导入列表均使用此组件
struct SoundRow: View {
    let name: String
    let isSelected: Bool
    let onPlay: () -> Void
    let onSelect: () -> Void

    @Environment(\.horizontalSizeClass) private var horizontalSizeClass

    var body: some View {
        Button(action: onSelect) {
            HStack(spacing: isPad ? 14 : 12) {
                Image(systemName: isSelected ? "checkmark.circle.fill" : "circle")
                    .font(.system(size: iconSize))
                    .foregroundColor(isSelected ? .accentColor : .secondary)

                Text(name)
                    .font(.system(size: soundFontSize))
                    .foregroundColor(.primary)

                Spacer()

                Button {
                    onPlay()
                    HapticService.shared.selection()
                } label: {
                    Image(systemName: "play.circle.fill")
                        .font(.system(size: playIconSize))
                        .foregroundColor(.accentColor.opacity(0.7))
                }
                .buttonStyle(.plain)
            }
            .padding(.vertical, isPad ? 14 : 8)
            .padding(.horizontal, isPad ? 16 : 12)
            .background(
                RoundedRectangle(cornerRadius: AppConstants.Layout.largeCardCornerRadius)
                    .fill(isSelected ? Color.accentColor.opacity(0.1) : Color.clear)
            )
            .contentShape(Rectangle())
        }
        .buttonStyle(.plain)
    }

    private var isPad: Bool { horizontalSizeClass == .regular }
    private var iconSize: CGFloat { isPad ? 24 : 20 }
    private var soundFontSize: CGFloat { isPad ? 18 : 16 }
    private var playIconSize: CGFloat { isPad ? 30 : 26 }
}
```

**SoundPickerView.swift** — 重构为分类浏览：

```swift
import SwiftUI

struct SoundPickerView: View {
    @Binding var selectedSound: String
    let previewVolume: Float    // 继承自 AlarmEditView 的 volume 绑定

    @Environment(\.horizontalSizeClass) private var horizontalSizeClass
    @State private var playingSound: String?

    private let categories = AppConstants.Sound.SoundCategory.allCases
    private let builtInSounds = AppConstants.Sound.builtInSounds

    var body: some View {
        ScrollView {
            VStack(alignment: .leading, spacing: sectionSpacing) {
                // 内置铃声 — 按分类分组
                ForEach(categories) { category in
                    let soundsInCategory = builtInSounds.filter { $0.category == category }
                    if !soundsInCategory.isEmpty {
                        SoundCategorySection(
                            category: category,
                            sounds: soundsInCategory,
                            selectedSound: selectedSound,
                            playingSound: playingSound,
                            onSelect: { name in
                                selectedSound = name
                                HapticService.shared.selection()
                            },
                            onPlay: { name in
                                playingSound = name
                                AudioService.shared.previewSound(soundName: name, volume: previewVolume)
                            }
                        )
                    }
                }

                // Apple Music 区域（M4 实现时启用，当前为占位）
                // appleMusicSection

                // 自定义导入区域（M5 实现时启用，当前为占位）
                // importedSection
            }
            .padding()
        }
    }

    private var sectionSpacing: CGFloat { horizontalSizeClass == .regular ? 20 : 16 }
}

/// 分类 Section — 每个分类的标题 + 铃声列表
private struct SoundCategorySection: View {
    let category: AppConstants.Sound.SoundCategory
    let sounds: [AppConstants.Sound.SoundInfo]
    let selectedSound: String
    let playingSound: String?
    let onSelect: (String) -> Void
    let onPlay: (String) -> Void

    var body: some View {
        VStack(alignment: .leading, spacing: 8) {
            HStack(spacing: 6) {
                Image(systemName: category.icon)
                    .foregroundColor(colorFromName(category.color))
                Text(category.displayName)
                    .font(.system(size: 15, weight: .medium))
                    .foregroundColor(.secondary)
            }

            ForEach(sounds) { sound in
                SoundRow(
                    name: sound.displayName,
                    isSelected: selectedSound == sound.displayName,
                    onPlay: { onPlay(sound.displayName) },
                    onSelect: { onSelect(sound.displayName) }
                )
            }
        }
    }

    /// 复用 SettingsView 中已有的颜色映射逻辑
    private func colorFromName(_ name: String) -> Color {
        switch name {
        case "red":    return .red
        case "green":  return .green
        case "blue":   return .blue
        case "orange": return .orange
        case "purple": return .purple
        default:       return .secondary
        }
    }
}
```

```swift
import Foundation
import MediaPlayer

/// 封装 Apple Music / iTunes 音乐库交互
/// 单例模式，与 AudioService/VolumeManager 等保持一致
final class MusicLibraryService: ObservableObject {
    static let shared = MusicLibraryService()

    @Published var authorized: Bool = false
    @Published var selectedItems: [MPMediaItem] = []   // 用户选择过的音乐库歌曲

    private init() {
        checkAuthorization()
    }

    func checkAuthorization() {
        let status = MPMediaLibrary.authorizationStatus()
        authorized = (status == .authorized)
    }

    func requestAuthorization(completion: @escaping (Bool) -> Void) {
        MPMediaLibrary.requestAuthorization { status in
            DispatchQueue.main.async {
                self.authorized = (status == .authorized)
                completion(self.authorized)
            }
        }
    }

    /// 保存选中的音乐库歌曲信息
    func saveSelectedSong(_ item: MPMediaItem) -> String {
        // 格式："appleMusic:{persistentID}"，存入 AlarmItem.soundName
        let identifier = "appleMusic:\(item.persistentID)"
        // 缓存歌曲元数据到 UserDefaults（名称、艺术家），避免每次重新查询
        cacheSongMetadata(item)
        return identifier
    }

    /// 从 persistentID 查询歌曲信息
    func song(for persistentID: UInt64) -> MPMediaItem? {
        let query = MPMediaQuery.songs()
        query.addFilterPredicate(MPMediaPropertyPredicate(
            value: NSNumber(value: persistentID),
            forProperty: MPMediaItemPropertyPersistentID
        ))
        return query.items?.first
    }

    /// 获取缓存的显示名（无需查询音乐库）
    func displayName(for identifier: String) -> String? {
        guard identifier.hasPrefix("appleMusic:") else { return nil }
        let cache = UserDefaults.standard.dictionary(forKey: "appleMusicCache") as? [String: String] ?? [:]
        return cache[identifier]
    }

    private func cacheSongMetadata(_ item: MPMediaItem) {
        let key = "appleMusic:\(item.persistentID)"
        var cache = UserDefaults.standard.dictionary(forKey: "appleMusicCache") as? [String: String] ?? [:]
        cache[key] = "\(item.title ?? "Unknown") - \(item.artist ?? "")"
        UserDefaults.standard.set(cache, forKey: "appleMusicCache")
    }
}
```

```swift
func playAlarm(soundName: String, volume: Float, source: SoundSource = .builtIn, fadeIn: Bool = false, fadeInDuration: Double = 5.0) {
    stopAlarm()
    beginBackgroundTask()
    VolumeManager.shared.boostSystemVolume(forAlarmVolume: volume)
    guard configureAudioSession() else { ... }

    switch source {
    case .builtIn, .imported:
        playLocalSound(name: soundName, volume: volume, fadeIn: fadeIn, fadeInDuration: fadeInDuration)
    case .appleMusic:

/// 播放 Apple Music 歌曲
private func playAppleMusicSound(identifier: String, volume: Float, fadeIn: Bool, fadeInDuration: Double) {
    guard identifier.hasPrefix("appleMusic:"),
          let persistentIDStr = identifier.split(separator: ":").last,
          let persistentID = UInt64(persistentIDStr) else {
        print("Invalid Apple Music identifier: \(identifier)")
        return
    }

    let player = MPMusicPlayerController.applicationQueuePlayer
    // 通过 persistentID 查询 MPMediaItem，再构造 MPMediaItemCollection 设置队列
    // 注意：persistentID 是音乐库内歌曲的标识，不是 storeID，不能用 MPMusicPlayerStoreDescriptorQueueDescriptor
    let query = MPMediaQuery.songs()
    query.addFilterPredicate(MPMediaPropertyPredicate(
        value: NSNumber(value: persistentID),
        forProperty: MPMediaItemPropertyPersistentID
    ))
    if let collection = MPMediaItemCollection(items: query.items ?? []) {
        player.setQueue(with: collection)
    } else {
        print("Apple Music song not found in library, falling back to default")
        playLocalSound(name: AppConstants.Sound.defaultSound, volume: volume, fadeIn: fadeIn, fadeInDuration: fadeInDuration)
        return
    }
    player.volume = volume  // 注意：MPMusicPlayerController 的音量控制与 AVAudioPlayer 不同

    if fadeIn {
        player.volume = AppConstants.Volume.fadeInMinStartVolume
        player.play()
        startFadeIn(targetVolume: volume, duration: fadeInDuration, startVolume: AppConstants.Volume.fadeInMinStartVolume)
    } else {
        player.play()
    }

    DispatchQueue.main.async {
        self.isPlaying = true
        self.currentVolume = volume
    }
}
```

**SoundImportService.swift** — 声音导入服务：

```swift
import Foundation
import UniformTypeIdentifiers

/// 封装自定义铃声的导入/列表/删除
/// 单例模式，与项目其他 Service 保持一致
final class SoundImportService: ObservableObject {
    static let shared = SoundImportService()

    /// 免费用户自定义导入数量上限，防止绕过 Premium 声音包
    static let freeImportLimit: Int = 1

    @Published var importedSounds: [ImportedSoundInfo] = []

    struct ImportedSoundInfo: Identifiable, Hashable {
        let id: String           // "imported:{fileNameNoExt}"
        let displayName: String  // 文件名（去扩展名）
        let fileName: String     // 完整文件名（含扩展名）
        let fileSize: Int64      // 文件大小
    }

    private let importedDir: URL

    private init() {
        let docs = FileManager.default.urls(for: .documentDirectory, in: .userDomainMask).first!
        importedDir = docs.appendingPathComponent("ImportedSounds", isDirectory: true)
        createDirectoryIfNeeded()
        refreshImportedSounds()
    }

    /// 当前用户是否还可以继续导入
    /// M5 阶段：所有用户统一按免费配额限制（1 个）
    /// M7 阶段：扩展为 `SubscriptionService.shared.isPremium || importedSounds.count < Self.freeImportLimit`
    var canImportMore: Bool {
        importedSounds.count < Self.freeImportLimit
    }

    /// 距离免费配额上限还差几个
    var remainingFreeImports: Int {
        max(0, Self.freeImportLimit - importedSounds.count)
    }

    /// 确保 ImportedSounds 目录存在
    private func createDirectoryIfNeeded() {
        if !FileManager.default.fileExists(atPath: importedDir.path) {
            try? FileManager.default.createDirectory(at: importedDir, withIntermediateDirectories: true)
        }
    }

    /// 刷新导入铃声列表
    func refreshImportedSounds() {
        let allowedExtensions = Set(["mp3", "m4a", "wav", "aiff", "caf"])
        let files = (try? FileManager.default.contentsOfDirectory(at: importedDir, includingPropertiesForKeys: [.fileSizeKey])) ?? []

        importedSounds = files.compactMap { url in
            let ext = url.pathExtension.lowercased()
            guard allowedExtensions.contains(ext) else { return nil }
            let name = url.deletingPathExtension().lastPathComponent
            let size = (try? url.resourceValues(forKeys: [.fileSizeKey]))?.fileSize ?? 0
            return ImportedSoundInfo(
                id: "imported:\(name)",
                displayName: name,
                fileName: url.lastPathComponent,
                fileSize: Int64(size)
            )
        }
    }

    /// 从 URL 导入文件（DocumentPicker 回调）
    /// - Returns: true 导入成功；false 失败或超出配额
    func importFile(from url: URL) -> Bool {
        // 配额检查：免费用户达到上限后禁止继续导入
        guard canImportMore else { return false }

        let fileName = url.lastPathComponent
        let destURL = importedDir.appendingPathComponent(fileName)

        // 防止覆盖
        if FileManager.default.fileExists(atPath: destURL.path) {
            return false
        }

        // 安全访问
        guard url.startAccessingSecurityScopedResource() else { return false }
        defer { url.stopAccessingSecurityScopedResource() }

        do {
            try FileManager.default.copyItem(at: url, to: destURL)
            refreshImportedSounds()
            return true
        } catch {
            print("Import failed: \(error.localizedDescription)")
            return false
        }
    }

    /// 删除导入的铃声
    func deleteSound(_ info: ImportedSoundInfo) -> Bool {
        let fileURL = importedDir.appendingPathComponent(info.fileName)
        do {
            try FileManager.default.removeItem(at: fileURL)
            refreshImportedSounds()
            return true
        } catch {
            print("Delete failed: \(error.localizedDescription)")
            return false
        }
    }
}
```

**SubscriptionService**：

```swift
// Services/SubscriptionService.swift
import Foundation
import StoreKit

/// 管理 IAP 订阅状态
/// 单例模式，与 MusicLibraryService 等风格一致
final class SubscriptionService: ObservableObject {
    static let shared = SubscriptionService()

    @Published var isPremium: Bool = false
    @Published var products: [Product] = []
    @Published var isLoading: Bool = false

    private init() {
        Task { await loadProducts() }
    }

    func loadProducts() async {
        // iOS 15+ StoreKit 2 API
        do {
            let ids = Set(SubscriptionProduct.all.map { $0.productId })
            products = try await Product.products(for: ids)
        } catch {
            print("Failed to load products: \(error.localizedDescription)")
        }
    }

    func purchase(_ product: Product) async -> Bool {
        isLoading = true
        defer { isLoading = false }
        do {
            let result = try await product.purchase()
            switch result {
            case .success(let verification):
                let transaction = try checkVerified(verification)
                await transaction.finish()
                isPremium = true
                return true
            case .userCancelled, .pending:
                return false
            @unknown default:
                return false
            }
        } catch {
            print("Purchase failed: \(error.localizedDescription)")
            return false
        }
    }

    func restorePurchases() async {
        do {
            for await result in Transaction.currentEntitlements {
                let transaction = try checkVerified(result)
                if transaction.productType == .autoRenewable {
                    isPremium = true
                    return
                }
            }
            isPremium = false
        } catch {
            print("Restore failed: \(error.localizedDescription)")
        }
    }

    private func checkVerified<T>(_ result: VerificationResult<T>) throws -> T {
        switch result {
        case .unverified:
            throw StoreError.failedVerification
        case .verified(let safe):
            return safe
        }
    }

    enum StoreError: Error {
        case failedVerification
    }
}
```

### M8：视频背景 / AI 铃声 / 随机铃声创新

#### 3.1 需求描述

在基础铃声和订阅模式之上，通过创新功能实现差异化竞争。参考 **Alarmy 2025 年 7 月推出的 Video Alarm 功能**（行业 #1，已经过市场验证），以及 Wonderwake 的随机铃声防止疲劳功能。

**M8.2 架构决策（基于竞品调研）**：

经调研 Alarmy 2025 年 7 月推出的 Video Alarm 功能，确认行业 #1 的设计哲学为 **"音视频完全分离"**：
- 视频被称为 **"Alarm Background"**（闹钟背景），而非 "Video Alarm"
- **"Sound" 和 "Alarm Background" 是两个独立菜单项**，用户分别设置
- 视频静音播放，声音由 Sound 设置独立决定
- 用户可自由组合：内置铃声 + 自定义视频背景 / Apple Music 歌曲 + 内置视频背景 / 纯音频无视频

**本计划采用分离式架构**，而非将音频和视频混在同一选择器：
- **跨类型分离**：Sound 菜单 + Video Background 菜单（符合单一职责）
- **类型内部统一**：SoundPickerView 统一三种音频来源，VideoBackgroundPickerView 统一三种视频来源
- **理由**：分离反而更清晰，避免用户混淆"声音"和"背景"概念；符合 Alarmy 经过市场验证的最佳实践

#### 3.2 设计规则

- **单一职责**：AI 铃声生成封装在 `AIGenerationService`；视频背景资源管理封装在 `VideoBackgroundService`；视频导入/截取/管理封装在 `VideoImportService`
- **可选依赖**：M8 不应影响 M1-M7 的核心功能，所有功能均为可选开启
- **代码复用**：视频背景响铃界面复用 `AlarmRingView` 的布局框架，仅替换背景为视频层；视频导入流程复用 M5 的 `DocumentPickerWrapper` 模式
- **风格一致**：AI 生成页沿用 `Form + Section` 设置风格；VideoBackgroundPickerView 沿用 SoundPickerView 的分类浏览模式
- **最小代码**：先实现最小可用版本（MVP），视频截取 MVP 优先使用系统 `UIVideoEditorController`
- **音视频解耦**：视频背景静音播放（`AVPlayer.isMuted = true`），声音由 Sound 设置独立决定，最大化组合灵活性

```swift
    /// 与 SoundImportService.freeImportLimit 策略一致
    static let freeImportLimit: Int = 1

    @Published var importedVideos: [ImportedVideoInfo] = []

    struct ImportedVideoInfo: Identifiable, Hashable {
        let id: String              // "videoImported:{fileNameNoExt}"
        let displayName: String     // 文件名（去扩展名）
        let fileName: String        // 完整文件名（含扩展名）
        let fileSize: Int64
        let thumbnailData: Data?    // AVAssetImageGenerator 生成的首帧缩略图
    }

    /// 视频存储目录：Documents/Videos/
    let importedDir: URL

    private init() {
        let docs = FileManager.default.urls(for: .documentDirectory, in: .userDomainMask).first!
        importedDir = docs.appendingPathComponent("Videos", isDirectory: true)
        createDirectoryIfNeeded()
        refreshImportedVideos()
    }

    /// 当前用户是否还可以继续导入
    /// M7 阶段扩展为：SubscriptionService.shared.isPremium || importedVideos.count < freeImportLimit
    var canImportMore: Bool {
        importedVideos.count < Self.freeImportLimit
    }

    var remainingFreeImports: Int {
        max(0, Self.freeImportLimit - importedVideos.count)
    }

    /// 从 URL 导入视频文件（PhotosPicker / DocumentPicker 回调）
    /// - Parameter sourceURL: 源视频 URL
    /// - Parameter trimRange: 截取范围 (start, duration)，nil 表示不截取
    /// - Returns: true 导入成功
    func importVideo(from sourceURL: URL, trimRange: (start: Double, duration: Double)?) -> Bool {
        guard canImportMore else { return false }

        let fileName = sourceURL.deletingPathExtension().lastPathComponent + "_alarm.mp4"
        let destURL = importedDir.appendingPathComponent(fileName)

        guard sourceURL.startAccessingSecurityScopedResource() else { return false }
        defer { sourceURL.stopAccessingSecurityScopedResource() }

        do {
            if let range = trimRange {
                // 使用 AVAssetExportSession 截取指定片段并压缩为 H.264 720p
                try trimAndExport(from: sourceURL, to: destURL, start: range.start, duration: range.duration)
            } else {
                // 直接压缩转码（控制大小）
                try compressAndExport(from: sourceURL, to: destURL)
            }
            refreshImportedVideos()
            return true
        } catch {
            print("Video import failed: \(error.localizedDescription)")
            return false
        }
    }

    /// 删除导入的视频
    func deleteVideo(_ info: ImportedVideoInfo) -> Bool {
        let fileURL = importedDir.appendingPathComponent(info.fileName)
        do {
            try FileManager.default.removeItem(at: fileURL)
            refreshImportedVideos()
            return true
        } catch {
            return false
        }
    }

    // MARK: - Private

    private func trimAndExport(from source: URL, to dest: URL, start: Double, duration: Double) throws {
        let asset = AVURLAsset(url: source)
        guard let exportSession = AVAssetExportSession(asset: asset, presetName: AVAssetExportPreset1280x720) else {
            throw NSError(domain: "VideoImportService", code: 1, userInfo: nil)
        }
        let startTime = CMTime(seconds: start, preferredTimescale: 600)
        let endTime = CMTime(seconds: start + duration, preferredTimescale: 600)
        exportSession.timeRange = CMTimeRange(start: startTime, end: endTime)
        exportSession.outputURL = dest
        exportSession.outputFileType = .mp4
        try exportSession.exportAsVideo()
    }

    private func compressAndExport(from source: URL, to dest: URL) throws {
        let asset = AVURLAsset(url: source)
        guard let exportSession = AVAssetExportSession(asset: asset, presetName: AVAssetExportPreset1280x720) else {

        }
        exportSession.outputURL = dest
        exportSession.outputFileType = .mp4
        try exportSession.exportAsVideo()
    }
```

**VideoBackgroundView.swift** — 响铃时视频背景播放组件：

```swift
// Views/Components/VideoBackgroundView.swift
import SwiftUI
import AVKit

/// 响铃界面的视频背景播放组件
/// 视频静音循环播放，声音由 AudioService 独立播放
/// 使用 AVPlayerLooper 实现无缝循环（actionAtItemEnd = .none 不会自动循环）
struct VideoBackgroundView: View {
    let videoName: String  // 含前缀的完整标识

    @State private var player: AVQueuePlayer?
    @State private var looper: AVPlayerLooper?

    var body: some View {
        VideoPlayer(player: player)
            .ignoresSafeArea()
            .onAppear {
                setupPlayer()
                player?.play()
            }
            .onDisappear {
                player?.pause()
            }
    }

    private func setupPlayer() {
        guard let url = resolvedURL else { return }
        let item = AVPlayerItem(url: url)
        let queuePlayer = AVQueuePlayer(playerItem: item)
        queuePlayer.isMuted = true  // 视频静音，声音由 AudioService 独立播放
        // AVPlayerLooper 实现无缝循环
        looper = AVPlayerLooper(player: queuePlayer, templateItem: item)
        player = queuePlayer
    }

    private var resolvedURL: URL? {
        // 根据 videoName 前缀解析 URL
        // videoBuiltIn: → Bundle/Videos/
        // videoImported: → Documents/Videos/
        if videoName.hasPrefix("videoBuiltIn:") {
            let name = String(videoName.dropFirst("videoBuiltIn:".count))
            return VideoBackgroundService.shared.urlForVideo(name)
        } else if videoName.hasPrefix("videoImported:") {
            let name = String(videoName.dropFirst("videoImported:".count))
            return VideoImportService.shared.importedDir.appendingPathComponent("\(name).mp4")
        }
        return nil
    }
}
```

### 4.3 AudioService 播放路由（音频）

```swift
// 在 AudioService 中根据 soundName 前缀判断来源：
func soundSource(for name: String) -> SoundSource {
    if name.hasPrefix("appleMusic:") { return .appleMusic }
    if name.hasPrefix("imported:")   { return .imported }
    return .builtIn
}
```

### 4.4 VideoBackgroundView URL 解析路由（视频）

```swift
// 根据 videoBackgroundName 前缀解析视频 URL：
func resolveVideoURL(_ name: String?) -> URL? {
    guard let name = name else { return nil }  // 无背景
    if name.hasPrefix("videoBuiltIn:") {
        let id = String(name.dropFirst("videoBuiltIn:".count))
        return VideoBackgroundService.shared.urlForVideo(id)
    } else if name.hasPrefix("videoImported:") {
        let fileName = String(name.dropFirst("videoImported:".count))
        return VideoImportService.shared.importedDir.appendingPathComponent("\(fileName).mp4")
    }
    return nil
}
```

### 4.5 向后兼容保证

- **音频**：已有闹钟的 `soundName` 均为纯字符串（如 `"Gentle Morning"`），`soundSource()` 返回 `.builtIn`，逻辑不变；Core Data 无需 schema migration
- **视频**：新增 `videoBackgroundName` 为可选字段，旧闹钟默认 `nil`，响铃时走原有渐变背景分支，逻辑不变

## 七、风险与注意事项

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 包体积增大 | 25 首新 .caf 文件约 8-12MB | 压缩音频质量至 44.1kHz/16bit，控制在 500KB/首 |
| Apple Music 需订阅 | 免费用户无法播放 Apple Music 歌曲 | UI 上明确标注"需要 Apple Music 订阅" |
| MPMediaItem 可被删除 | 用户删歌后闹钟无法播放 | `playAppleMusicSound` 失败时 fallback 到默认铃声 |
| iOS 后台播放限制 | Apple Music 后台播放可能被中断 | 使用 `MPMusicPlayerController.applicationQueuePlayer`（系统级播放器） |
| ImportedSounds 权限 | Documents 目录文件可能被系统清理 | 仅缓存非关键数据，引导用户保留源文件 |
| Core Data 兼容 | soundName 格式扩展 | 纯 String 字段，无需 migration |
| IAP 审核被拒 | 订阅定价、恢复购买、隐私政策不符合 App Store 规范 | 提供 Restore Purchases 按钮、在隐私政策中说明订阅条款、使用 Apple 官方 StoreKit 2 API |
| 包体积继续增大（M7） | Premium 声音包额外 90 首约 30-45MB | 采用按需下载（On-Demand Resources）或 CDN 分发，避免一次性打包 |
| 视频资源过大（M8） | 视频文件打包会显著增加 App 体积 | 视频资源不打包，使用 CDN 下载 + 本地缓存 |
| AI 生成版权风险（M8） | 使用第三方 AI 音乐 API 可能产生版权争议 | MVP 使用设备端合成，后续接入 API 时审查服务条款 |
| 功能复杂度失控（M8） | 视频/AI 功能可能影响核心稳定性 | M8 所有功能默认关闭，通过 Feature Flag 控制，不影响 M1-M7 核心路径 |
